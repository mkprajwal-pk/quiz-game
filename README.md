# quiz-game
beginner-friendly Python quiz game featuring computer-related questions, score tracking, and interactive command-line gameplay.
Python Quiz Game 🎮

A simple and interactive Quiz Game built with Python for beginners to practice basic programming concepts such as input(), conditional statements, string methods, variables, and arithmetic operations.

📌 Features
Asks the player whether they want to play.
Takes the player's name and welcomes them.
Contains 5 computer-related questions.
Checks answers using case-insensitive comparison.
Keeps track of the player's score.
Displays the total number and percentage of correct answers.

🧠 Topics Covered
Python input() function
if-else statements
Variables
String methods (.lower())
Arithmetic operations
User interaction
Basic score calculation

🚀 How to Run
Make sure Python is installed on your computer.
Download or clone this repository.
Open a terminal in the project folder.
Run:
python quiz.py
Follow the instructions displayed in the terminal and enjoy the quiz!


🎯 Purpose

This project was created as a beginner-friendly Python project to practice programming fundamentals and build a simple command-line application.

Feel free to modify the questions, add more questions, improve the scoring system, or add new features!
